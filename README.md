# Agentic Engineering — Fieldnotes

A responsive, single-page course-site concept about engineering with AI agents. It is a standalone front-end built with semantic HTML, CSS, and vanilla JavaScript; no build step or package installation is needed.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server, for example:

```sh
npx serve .
```

## Included

- Responsive navigation with an accessible mobile menu
- Nine-step curriculum overview
- Anchor navigation, reduced-motion support, and a reading progress indicator
- Original branding and copy with no framework dependencies
