# Agentic Engineering — Course + Fieldnotes

A responsive Agentic Engineering course page with a built-in design switcher. The original, green-and-black Course view is the default. Fieldnotes opens the yellow, cream, and black editorial alternative, with the same workflow and course information. Both views are standalone front ends built with semantic HTML, CSS, and vanilla JavaScript; no build step or package installation is needed. The alternate design can be shared directly using `?design=fieldnotes`.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server, for example:

```sh
npx serve .
```

## Included

- Accessible switcher between the original Course UI and the Fieldnotes UI
- Responsive navigation with accessible mobile menus in both views
- Matching nine-step curriculum in both designs
- Five practical course tracks, from fundamentals to reusable agent skills
- Native, keyboard-accessible FAQ disclosures in both designs
- Anchor navigation, reduced-motion support, and a reading progress indicator
- Original Course and Fieldnotes styling and copy with no framework dependencies
